# ASKID
## Amnezia Self-hosted Key IP to Domain
Инструмент для замены IP сервера в ключе конфигурации на доменное имя.
### Зачем?
Если клиент подключается к серверу по IP, то, когда IP сервера поменяется (после блокировки, смены локации и т.п.), клиент потеряет доступ.
Но если он подключается по домену, то, даже если IP сервера поменяется, он не потеряет доступ.

В теории должно работать. Использую это для изменения ключей Amnezia. Для удобства захотел опубликовать статическую страницу с нужным скриптом.
Сама страница написана ИИ, идея тоже его
